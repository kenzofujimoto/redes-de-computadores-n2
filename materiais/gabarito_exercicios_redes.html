Questão 1172.31.10.0/25

Rede 172.31.10.0/25 — quais afirmações são corretas?

Cálculo base

Prefixo /25 → bits de host = 32 - 25 = 7 IPs totais = 2^7 = 128 Hosts úteis = 128 - 2 = 126 Máscara = 255.255.255.128 Em binário = 11111111.11111111.11111111.10000000 Endereço de rede: 172.31.10.0 1º IP válido: 172.31.10.1 Último IP válido: 172.31.10.126 Broadcast: 172.31.10.127

Análise das afirmações

✅ I — CERTA: 126 hosts utilizáveis (2^7 − 2 = 126)

✅ II — CERTA: Rede = 172.31.10.0 e Broadcast = 172.31.10.127 ✓

✅ III — CERTA: Máscara 255.255.255.128 em binário = 11111111.11111111.11111111.10000000 ✓

❌ IV — ERRADA: Último IP válido é 172.31.10.126 (não .128). .128 seria a próxima rede!

Resposta: D) I, II e III, apenas.
Questão 2Roteamento

Empresa de refrigerantes — roteamento estático vs dinâmico

Análise das afirmações

✅ I (Caio) — CERTA: Roteamento estático é configurado manualmente e NÃO considera carga dos roteadores vizinhos. Correto.

✅ II (Pedro) — CERTA: Se roteadores dinâmicos perdem comunicação, ficam sem informação da topologia. Rotas estáticas diretas garantem comunicação independente de protocolos. Correto.

❌ III (João) — ERRADA: Rotas estáticas NÃO demandam mais recursos de rede. É o oposto: roteamento dinâmico gasta CPU e banda para troca de mensagens de rota. Estático é "mudo" na rede.

Resposta: B) I e II, apenas.
Questão 3TCP / IP / UDP

Relacione protocolos às características

Protocolos: (A) TCP | (B) IP | (C) UDP □ Provê serviço de transporte NÃO orientado para conexão à aplicação. → (C) UDP □ Provê à aplicação serviço de transporte ORIENTADO para conexão. → (A) TCP □ Provê comunicação lógica entre hospedeiros, mas SEM garantia de entrega. → (B) IP □ Provê serviço de transporte CONFIÁVEL à aplicação. → (A) TCP □ Provê um modelo de serviço de entrega de MELHOR ESFORÇO entre hospedeiros. → (B) IP □ Provê serviço de transporte NÃO CONFIÁVEL à aplicação. → (C) UDP

Sequência: C, A, B, A, B, C

Resposta: D) C, A, B, A, B, C

Questão 5/26 – Sub-redes

4 dispositivos com /26 — em quais sub-redes estão?

Sub-redes /26 do bloco 192.168.1.0 e 192.168.2.0

Com /26: bloco = 64 IPs → sub-redes a cada 64 192.168.1.0/26: .0 – .63 (hosts .1 – .62) 192.168.1.64/26: .64 – .127 (hosts .65 – .126) 192.168.1.128/26:.128 – .191 (hosts .129 – .190) Dispositivo A: 192.168.1.50 → sub-rede 192.168.1.0/26 ✓ Dispositivo B: 192.168.1.80 → sub-rede 192.168.1.64/26 ✓ └─ A e B estão em sub-redes DIFERENTES 192.168.2.128/26:.128 – .191 192.168.2.192/26:.192 – .255 Dispositivo C: 192.168.2.135 → sub-rede 192.168.2.128/26 ✓ Dispositivo D: 192.168.2.185 → sub-rede 192.168.2.128/26 ✓ └─ C e D estão na MESMA sub-rede
Resposta: D) A e B em sub-redes diferentes; C e D na mesma sub-rede.
